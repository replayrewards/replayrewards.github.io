FAQ

Fair questions.

Is the data real, or a demo simulation?
Real. Get Insightful executes genuine Airbyte connectors (via PyAirbyte) against your sources and lands typed tables in the warehouse. The bundled Genzeon engineering tenant is a sample dataset — the pipelines moving it are not mocked.
Where does my data live?
In a Postgres database you run locally (docker compose ships in the repo). Dashboards, chat history, entities, and memories are rows in your database. Only LLM requests leave the machine, and they go to whichever provider you configure.
Which AI models does it support?
Anything speaking the Anthropic protocol. There are first-class presets for Anthropic and for Z.ai’s GLM endpoint, and you can point it at any compatible base URL with a key.
Can my existing agents and tools use it?
Yes — every instance exposes an MCP server at POST :3000/mcp with context_search, run_sql (read-only), and list_tables. Claude Desktop and Cursor work out of the box; there’s also a REST API and an agent guide for authoring dashboards programmatically.
What’s the stack?
Tauri 2 desktop app with an embedded axum server, sqlx over Postgres, React 19 front end, PyAirbyte for connector runs. The whole thing cold-starts from one script: ./run.sh.
